AdviCue AI - Setup and Run

1. Install Python 3.14 x64 or 3.12 x64.
2. Extract the complete ZIP to a new folder. Restart the PC if an older AdviCue is still running.
3. Run SETUP_WINDOWS.bat once, with internet for local AI software and models.
4. Run RUN_WINDOWS.bat and open http://127.0.0.1:8000.
5. Click Enter AdviCue. There is no email or password form.

The approved fictional sample book is included for fresh installations. Existing records are preserved. No models are included in the ZIP. Normal operation after setup is offline. Anyone using this PC can enter the configured advisor workspace. Do not expose the server on a public network.

This guide replaces the credential-login steps in older judge guides.
